# AGENTS.md — Daggerfall-Online-RU-localization

> Прочти этот файл первым в каждой сессии. Нарушение любого MUST — стоп и спроси человека.

## 0. Что это за репозиторий

Независимый RU-оверлей для https://github.com/Lattymoy/daggerfall-js-source (см. верх README). MUST: ноль изменений баланса, сетевого протокола (`worldXXX`), формата сейвов. Конфликтов с оригиналом и его сервером быть не должно: мы поставляем данные (`ru.json`, `-LOC`, шрифт) + тонкий лоадер, а не копию клиента.

## 1. Pay once — качество сразу, без костылей

- MUST: «ID внутри, текст только на рендере». В сеть (`chat`, `trade`, `quest share`), в сейвы и в логику квестов уходят только ключи/ID (`templateId`, `questName`, row-ключи). Локализованная строка никогда не персистится и не отправляется.
- MUST: ключ стабилен. `Key` из `Internal_Strings`/апстрима не переименовывать; переводить только `Value`. Удаление ключа из `en.json` запрещено — только deprecate.
- MUST: разметку не переводить: `[/center]`, `[/record]`, `[/end]`, `%pcn`, `%di`, `%s`, `<-->` остаются как есть; перевод вокруг них.
- MUST: fallback EN. Отсутствующий RU-ключ = английский текст + варнинг в консоль, не `?`, не краш, не пустота.
- MUST: грамматика через ICU + запечённые формы (`{count, plural, one/few/many}`, `{gender, select}`), никаких `if (n==1)` в проде и никакой морфологии в рантайме. Падежи (напр. `15 Января`) — полем словаря, не хардкодом.
- MUST: шрифт Handjet, веса только 400/500/700. Веса 100/200/300 запрещены (точечный конструкт, нечитаемы). Неизвестный глиф → `?` (`FNT_ERROR_CODE`), не пробел-молчание.
- MUST: UTF-8 без BOM во всех `*.json/*.txt/*.csv`; `Ё/ё` обязательна.
- MUST NOT: вендорить шрифты с `personal use` лицензией (напр. Pixel Cyrillic VM Studio). Только OFL.
- MUST NOT: править `QBN:` (логику квестов) в `-LOC` файлах — только `QRC:`.

## 2. Переключатель языка (только безопасный вариант)

- Разрешён только ре-рендер: `setLocale('ru'|'en')` + перерисовка открытых DOM-поверхностей и инвалидация SDF-атласа. MUST NOT: перезапуск сессии, переподключение к релею, перезапись сейва, смена `worldXXX`-версии.
- Сеть при переключении молчит: язык — чисто клиентское состояние, сосед по чату ничего не замечает (он рендерит на своей локали по ID).
- Незаконченный бой/трейд/диалог при переключении: текущий фрейм договаривает на старом языке, новые строки — на новом. MUST: ни один in-flight `trade`/`cast`/`quest share` не перекодируется.

## 3. Инженерия (TDD обязателен)

- Каждый прод-файл — сначала падающий тест (`node --test test/<name>.test.js`), смотришь RED, потом GREEN, потом коммит. Тест, который не видел RED, не существует.
- Команды: `node --test test/` (всё), `node --test test/<file>` (точечно). Node ≥ 20 (import attributes `with { type: 'json' }`).
- Коммиты: `feat(locale): ...`, `feat(font): ...`, `feat(ru): ...`, `fix(...)`. Один таск — один осмысленный коммит минимум; пушить только зелёное.
- Теги: `locale-vX.Y` после каждой завершённой задачи плана.
- Перед PR в апстрим: `npm run check` эквивалент + скрин EN до/после попиксельно совпадает.

## 4. Структура

- `src/locale/locale.js` — лоадер и `t()`; `src/locale/en|ru.json` — таблицы; `src/locale/ru/quests|books/` — `-LOC` данные.
- `vendor/handjet/` — только 400/500/700 woff2+ttf + `OFL.txt`. `tools/` — `jagget-import.mjs`, `bake-ru-forms.mjs`, `pack-ru.mjs` (идемпотентные).
- `docs/ATTRIBUTION.md` — Jagget (с пометкой о разрешении), Handjet/Rosetta, DFU/Interkarma, Lattymoy. `docs/superpowers/plans/` — план-аргумент.
