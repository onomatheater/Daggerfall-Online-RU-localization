# Иконка окна и установщика

- `icon-src.png` — иконка Daggerfall Online из их репозитория
  (`daggerfall-js-source`, MIT © Lattymoy, `public/icons/icon-512.png`
  на пине пробы; NOTICE — `updater/launcher/NOTICE.md`).
  Взята по слову человека 12.10, только для окна апдейтера (не игры).
- `icon.ico` — сборка из `icon-src.png` командой `npm run icons`
  (пакет `png-to-ico`, мультиразмер). Коммитится готовым, чтобы `dist`
  работал без генерации.
