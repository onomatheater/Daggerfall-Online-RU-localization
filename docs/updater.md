# Апдейтер перевода (RU-пак)

## Установка

1. Скачай `ru-pack.zip` из релизов приватного репозитория.
2. Распакуй рядом с игрой / выбери «Русский» в панели языка.
3. Всё: версия игры определяется сама, подходящий пак выбирается сам.

## Как выбирается пак

- У пака есть клеймо совместимости: точная версия игры (`game`)
  или проверенный диапазон (`gameMin`–`gameMax`).
- Под твою версию берётся новейший совместимый пак.
- Подходящего нет — остаёшься на старом паке (или английском),
  ничего не ломается и не требует переустановки.

## Приватность

- Апдейтер только скачивает два статических файла (список паков и сам zip)
  и только когда ты сам открыл панель языка или нажал «проверить».
- Скачанный zip сверяется с sha из списка паков до установки:
  подменённый или битый файл дальше не идёт, остаёшься на старом паке.
- Ноль отправки: ни ID игрока, ни железо, ни телеметрия, ни отчёты
  об ошибках никуда не уходят. Язык — client-side: чат и сейвы
  оперируют ID, сосед по чату твой язык не видит.

## Откат

Предыдущий `ru-pack.zip` остаётся на диске: не понравилось обновление —
выбери его в панели языка. Переустанавливать игру не нужно.

## Неполадки

- Остался английский после обновления игры: пак под новую версию
  ещё не собран — жди следующий `ru-pack`, игра при этом работает.
- «Пак отклонён»: битый zip — скачай заново из релизов.
