# Апдейтер перевода (RU-пак)

## Приложение (рекомендуемый путь)

Отдельное окно, дабл-клик — и всё:

1. Запусти `updater/updater.bat`.
2. Нажми «Проверить обновления» — приложение само определит версию игры
   и скажет, есть ли пак новее.
3. Нажми «Установить» — пак скачается, сверится по sha, встанет.
   Не подошёл — кнопка «Откатить» вернёт предыдущий.

`.exe` для релиза собирается из `updater/` командой `npm run dist`
(electron-builder, NSIS-установщик в `updater/release/`, без подписи).
Чеклист релиза (решения человека): 1) стабильный URL фида вместо
`example.invalid` в `updater/main.js` (`FEED_URL`, стенд — `RU_FEED_URL`);
2) подпись установщика и канал доставки.

## Обновление игры (отдельно от пака)

Апдейтер — полная замена оригинального: игру обновляет сам, пак — сам,
друг другу не мешают.

- Баннер «Вышла версия игры X» + кнопка на страницу релизов (их notice-механика:
  сравнение тегов, мусор = тишина). Установщик не качаем: ставишь руками.
- После ручного обновления кнопка «Восстановить перевод»: версия → разовая
  миграция на распакованную установку (бэкап asar) → рецепт из фида → маркеры.
  Итог — «Перевод возвращён.»; нет рецепта — честно английским.
- Новости игры в ленте — их releases API при каждом старте.

Новости в ленте — общие: сначала игровые (их releases API — тянутся при
каждом старте, как в их лаунчере: один GET к публичным релизам, без данных
пользователя), затем пак из проверки (поле `notes` фида), затем стоящий пак.
Лента не пустует никогда. Проверка пака и скачивание — только по кнопке
или включённой автопроверке.

## Вручную (тулзы, без окна)

## Как выбирается пак

- У пака есть клеймо совместимости: точная версия игры (`game`)
  или проверенный диапазон (`gameMin`–`gameMax`).
- Под твою версию берётся новейший совместимый пак.
- Подходящего нет — остаёшься на старом паке (или английском),
  ничего не ломается и не требует переустановки.

## Приватность

- Апдейтер только скачивает два статических файла (список паков и сам zip)
  и только когда ты сам открыл панель языка или нажал «проверить».
- Скачанный zip сверяется с sha из списка паков до установки:
  подменённый или битый файл дальше не идёт, остаёшься на старом паке.
- Ноль отправки: ни ID игрока, ни железо, ни телеметрия, ни отчёты
  об ошибках никуда не уходят. Язык — client-side: чат и сейвы
  оперируют ID, сосед по чату твой язык не видит.

## Откат

Предыдущий `ru-pack.zip` остаётся на диске: не понравилось обновление —
выбери его в панели языка. Переустанавливать игру не нужно.

## Неполадки

- Остался английский после обновления игры: пак под новую версию
  ещё не собран — жди следующий `ru-pack`, игра при этом работает.
- «Пак отклонён»: битый zip — скачай заново из релизов.
